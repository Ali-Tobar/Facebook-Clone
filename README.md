# Facebook Clone UI

A responsive Facebook UI clone built with pure HTML5, CSS3 (Flexbox), and FontAwesome icons.

## Features
- Left navigation sidebar with custom hover effects.
- Stories section with horizontal touch scroll.
- Responsive design adapted for Mobile, Tablet, and Desktop screens.
- Feed cards with interactive-style reaction buttons.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Media Queries)
- FontAwesome Icons
